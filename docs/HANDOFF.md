## 3. เรื่อง UI — สรุปให้ session หน้าเข้าใจใน 1 นาที

**ลูกค้าปฏิเสธ 2 รอบแรก** ("ไม่สวย ไม่สบายตา") รอบที่ 3 ผ่าน สาเหตุที่แท้จริงวัดได้เป็นตัวเลข
(ดู [`spec/ux-research-2026.md`](spec/ux-research-2026.md)): ตัวอักษร 79% เล็กกว่า 13px (เล็กสุด 10px),
line-height 1.5 ทั้งที่**อักษรไทยต้องการ 1.7** เพราะมีวรรณยุกต์บน–ล่างบรรทัด, กล่องมีขอบ 12 ใบต่อหน้า, ป้ายสี 4 สี

**สิ่งที่ล็อกไว้แล้วและห้ามแก้โดยไม่ถาม** (`apps/web/src/theme.css` เป็น SSOT):
- ตัวเนื้อหา **16px · line-height 1.7** · **เล็กสุดในระบบ 13px**
- ฟอนต์ **IBM Plex Sans Thai** (ไม่มีหัว) สำหรับ UI · **Trirong** เฉพาะหัวเรื่องและเอกสาร
- สีบอกสถานะเท่านั้น — แดง `#A8342A` ต้องจัดการ · ทอง `#B08829` กำลังดำเนินการ · เขียว `#2C5240` เรียบร้อย
- `--gold` ใช้เฉพาะของที่เป็นเกียรติบัตร/เอกสารทางการ ไม่ใช่ของตกแต่ง
- ไอคอนเป็น **SVG เส้น** viewBox 24 stroke 1.7 `currentColor` — **ห้ามใช้ emoji**

**กติกากระบวนการที่ได้มาจากการถูกปฏิเสธ 2 รอบ:** ห้ามทำครบทุกหน้าแล้วค่อยให้ลูกค้าดู
ต้องเสนอ 2–4 ทิศทางบนหน้าจอเดียวกันให้เลือกก่อน แล้วค่อยขยาย

## 4. ต้นแบบหน้าจอ — ดูและแก้อย่างไร

**ดู:** https://claude.ai/code/artifact/cb754cde-f073-42ab-ac60-7ebeacf95bfd
(แบ่ง 4 กลุ่ม สลับได้จากแถบเครื่องมือ: เริ่มงาน · จัดงานและวิทยากร · ผลการอบรม · การเงินและระบบ)

**แก้:** ทุกหน้าอยู่ที่ `docs/design/*.dc.html` — สร้างใหม่ด้วย

```bash
cd docs/design && python3 _scaffold.py    # อ่าน bodies/*.py → เขียน *.dc.html
```

`_scaffold.py` ดึง helmet + แถบเมนู มาจาก **`Jobs.dc.html`** (หน้าที่อนุมัติแล้ว) → ทุกหน้าใช้ชุดเดียวกันเสมอ

> ⚠️ **ข้อควรรู้:** 6 หน้าแรก (`Main` `Jobs` `Job` `Booking` `Certificate` `Mobile`) เขียนเป็น `.dc.html`
> ด้วยมือก่อนจะมี `_scaffold.py` จึง **ไม่มีไฟล์ `bodies/*.py`** — แก้ต้องแก้ `.dc.html` ตรง ๆ
> อีก 10 หน้ามี body source ครบ. ถ้ามีเวลาว่าง ควรย้าย 6 หน้านั้นเข้า `bodies/` ให้เหมือนกันทั้งหมด

**เผยแพร่ใหม่หลังแก้:** ใช้ skill `design` (seed แล้ว publish ทับ URL เดิม) — อย่าแก้ไฟล์
`trainflow-ui-directions.html` โดยตรง มันถูก generate และไม่ขึ้น git
